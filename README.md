# 扭蛋机控制器固件 (Niudan Machine Firmware)

本项目是基于 **STM32F10x** 微控制器的扭蛋机（扭蛋/胶囊玩具自动贩卖机）控制器固件及硬件设计文件。

## 项目概述

扭蛋机是一种投币式胶囊玩具贩卖机，玩家投入硬币后机器会自动转出一个胶囊玩具。本项目提供完整的控制器解决方案，包括：

- STM32F10x 系列微控制器固件（C 语言编写）
- PCB 电路原理图与布局文件
- 与乐摇摇运营管理系统的通信协议实现

|------|------|------|

### 系统特性

- **投币计数**：记录每日/累计投币数量
- **出蛋控制**：精确控制出蛋时序与超时检测
- **网络连接**：支持 WiFi 联网（通过 WiFi 模块）
- **运营管理**：通过乐摇摇协议与运营平台对接（上报库存、收款等）
- **设备加密**：支持设备 ID 与通信加密
- **远程设置**：支持远程修改游戏参数（投币数、时间等）

## 开发环境

- **IDE**：Keil MDK（项目文件：`niudan_src.uvprojx`）
- **MCU**：STM32F10x 系列
- **固件库**：STM32F10x 标准外设库（CMSIS）

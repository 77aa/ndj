# 扭蛋机（NDJ）固件与硬件项目

## 项目简介

本项目是一款**扭蛋机（Gashapon Machine）**的开源固件与 PCB 硬件设计，基于 STM32F103RE 微控制器（ARM Cortex-M3），兼容**乐摇摇**平台串口通信协议。

扭蛋机是一种投币式自动出球（蛋）机器，常见于商场、游戏厅等场所。本项目提供了完整的主控固件源代码和电路设计文件，可用于二次开发或学习参考。

## 固件功能

- **投币管理**：检测并统计投币次数，支持多币一局设置
- **出蛋控制**：电机驱动，支持出蛋超时检测与故障报警
- **灯光控制**：多路 LED 状态控制，支持电流采样
- **按键输入**：开门键、功能键等多路按键检测
- **WiFi 联网**：支持 WiFi 配置，连接后台服务器上报数据
- **乐摇摇协议**：兼容乐摇摇平台串口标准通信协议（V1.1.3）
- **RS-485 通讯**：支持 RS-485 总线与上位机/网关通信
- **EEPROM 存储**：保存游戏参数、统计数据等持久化配置
- **看门狗**：硬件看门狗，增强系统稳定性

## 开发环境

- **IDE**：Keil MDK（μVision5）
- **目标芯片**：STM32F103RE
- **固件库**：STM32F10x 标准外设库

### 编译步骤

1. 安装 [Keil MDK](https://www.keil.com/download/product/) 并配置 STM32F103RE 设备包
2. 打开 `niudan_src_new V2.9.21.7.3 leyaoyao/niudan_src.uvprojx`
3. 编译工程，生成 `.hex` 或 `.bin` 固件文件
4. 使用 ST-Link 或串口 ISP 将固件烧录到目标板
